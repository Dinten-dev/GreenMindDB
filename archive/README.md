# Historical one-off tools

These files are retained for source history and are excluded from maintained application entry points.
They are unsupported and must not be run as setup, deployment or account-management procedures.

| File | Historical purpose |
| --- | --- |
| `get_token.py`, `run_remote.sh` | Ad-hoc server token extraction using environment-specific paths |
| `trigger_sms.py` | One-off experimental biosignal request |
| `update_walkthrough.py` | Developer-local report update |
| `old_sensor.tsx` | Superseded sensor page |

Use the [backend guide](../backend/README.md), [administration reference](../docs/development.md)
and [release procedure](../deploy/release/README.md).
